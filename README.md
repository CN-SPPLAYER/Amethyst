**Among Us 反作弊与辅助模组**

## 简介

Amethyst（紫晶）是一个在**私人房间**内使用的 Among Us 反作弊模组。它通过捕获“不可能发生的 RPC”（如平民击杀、平民破坏、会议中进管、替他人进管、管道踢人漏洞等）来判断玩家是否使用外挂，并在主机端选择 **提醒 / 踢出 / 封禁**。同时也集成了玩家进出检测、黑白名单、等级守卫以及多项对局体验优化。

> 本模组**仅限房主在自己的私人房间中使用**，请勿在公开房间使用以避免影响他人游戏体验。

## 功能特性

### 🛡 RPC 反作弊（Guard）

- **RPC 检测**：捕获不可能的 RPC（平民击杀、平民破坏、无权限进管、伪造管道 ID、会议中进管/破坏/关门、地图外破坏、变形/隐身等角色越权行为）
- **丢弃 RPC**：主机端可丢弃被判定的异常 RPC 数据包，使其不生效
- **处理方式**：对作弊者可选择 **无 / 警告 / 踢出 / 封禁**
- **RPC 洪水检测**：检测单客户端高频刷 RPC（仅提醒，不拦截）
- **早期会议拦截**：拦截开局 15 秒内（含倒计时）的会议/报告
- **大厅伪造会议拦截**：阻止大厅中被伪造的会议 UI

### 🚪 进管 / 滑索防护

- **管道规则（主机 / 非主机独立开关）**：会议中进管、无权进管、伪造管道 ID、替他人进管
- **防强制进管 / 防被踢出管道**：拦截针对本机的强制透传与顶出
- **防管道踢人漏洞（vent-kick）**：主机端处罚发送该漏洞包的客户端
- **防强制滑索**：拦截针对本机的强制滑索
- **反作弊服务器绕过（ForceDTLS）**：通过 DTLS 绕过服务器对“非房主动作”的 RPC 反作弊，使离线端拦截更可靠

### 🕵 玩家管理（Players）

- **进出检测**：显示加入玩家的昵称、平台、等级等
- **封禁 / 白名单**：按 FriendCode 进房即踢，支持仅白名单模式
- **昵称封禁 / 平台封禁**：按昵称或原始平台名拉黑
- **等级守卫**：可设置最低 / 最高等级并选择动作
- **昵称历史**：按 FriendCode 记忆昵称并在改动时提示
- **机器人提示**：显示/隐藏机器人（bot）加入提示

### 🌊 网络 / 防崩溃防护（可选，默认关闭）

- 丢弃针对本机的强制位置传送（SnapTo）
- 丢弃超大 GameData 包（防大消息崩溃/超载）
- 丢弃非法/畸形类型的 GameData 子消息
- 加固 `PackedUInt` 反序列化，抵御畸形定长整数
- 防护 `VotingComplete` 超大投票数组导致的分配超载
- **Spawn 洪水防护**：裁剪单帧海量生成，防卡死/崩溃（进房/开局 5 秒宽限）

### 🧩 躲猫猫（Hide & Seek）模式防护

- 检测并拦截 H&S 中的**报告 / 关门 / 破坏 / 非法进管（强制传送）**等异常行为，可独立于主 RPC 守卫单独开关

### 👥 房间与会话

- **会议显示房主**：开会时左上角显示房主（图标 + 名字）
- **死后 / 存活身份显示**：死后显示全场身份；存活时可显示自己的身份、内鬼队友身份
- **匹配中解锁踢/封**：房主可在对局中踢人/封禁
- **自动返回大厅**、**NoWin（不结束对局）**

### 🎮 对局体验（QoL）

- **解锁 240 FPS**
- **更佳聊天**：富文本输入、复制粘贴、气泡动画、暗色主题
- **击杀/死亡动画跳过**、**任务快捷**、**装扮保存与一键切换**
- **解锁全部装扮**、**破坏冷却显示**、**更好的 ping/冷却显示**
- **房间查找增强**：最多展示 10 个房间（可滚动）、每行显示房主名/平台/房号
- **菜单悬浮按钮**（触屏友好）、**跳过断线惩罚**

### 🔍 模组客户端识别

- 可在房间中识别并标记其他兼容的模组客户端（开启时，他人也可能看到你在使用本模组）

### 🎨 个性化

- 多语言：**中文 / English / Русский**
- UI 主题与缩放可调；可选屏蔽遥测/崩溃上报以保护隐私

## 安装说明

> Amethyst 需要 **BepInEx (IL2CPP, Windows x64)** 运行环境。

1. 下载并安装 **BepInEx BleedingEdge — IL2CPP (`win-x64`)**
2. 找到 Among Us 安装目录：
   - **Steam**：库 → 右键 Among Us → 管理 → 浏览本地文件
   - **Epic**：库 → Among Us → 管理，通常位于 `C:\Program Files\Epic Games\AmongUs`
3. 将 BepInEx 解压到游戏目录（与 `Among Us.exe` 同级）
4. 先启动游戏一次到主菜单再关闭（会生成 `BepInEx/plugins` 目录）
5. 将 **`Amethyst_v1.0.3.dll`** 放入 `BepInEx/plugins/`
6. 启动游戏，按 `Insert` 打开菜单

> 首次启动会生成配置文件 `BepInEx/config/`，删除对应 `.cfg` 可重置设置。

## 反作弊提示

反作弊命中会弹出提示并按设定处理（提醒/踢出/封禁）。常见判定包括但不限于：

| 类别 | 说明 |
|:-----|:-----|
| 平民击杀 | 平民角色发起击杀 |
| 平民破坏 / 地图外破坏 | 平民或在非法位置发起破坏 |
| 快速破坏 | 极短时间内对不同系统连续破坏 |
| 会议中进管 / 破坏 / 关门 | 会议期间的不可能行为 |
| 无权进管 / 伪造管道 ID | 无权限进管或使用伪造管道 ID |
| 替他人进管（强制透传） | 检测到将他人强制送入/顶出管道（中性提示，不冤枉受害者） |
| 管道踢人漏洞 | vent-kick 漏洞利用 |
| 强制滑索 | 强制滑索使用 |
| 已知作弊菜单特征 | 检测到已知作弊菜单的 RPC 签名 |
| H&S 报告/破坏/关门/非法进管 | 躲猫猫模式异常 |
| 大厅游戏 RPC | 未开局时伪造的击杀/会议/变形等对局 RPC |
| RPC 洪水 | 单客户端高频刷 RPC（仅提醒） |

## 从源码构建

需要 Among Us 游戏程序集引用（`Assembly-CSharp.dll` 等），工程通过 `GameRefsDir` 指向游戏解包引用目录。

```
dotnet build src/Amethyst.csproj -c Release
```

构建产物为 `src/bin/Release/net6.0/Amethyst.dll`（及带版本号副本 `Amethyst_v1.0.3.dll`）。
